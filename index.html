Using it with family

Install the app on each family member's own phone. Everyone's entries stay on their own phone and nobody else can see them. If two people share one phone, use separate profiles below. Profiles are for keeping things tidy and are not locked with a password. Your data lives only on this phone, so tap Back up now and then and keep the file safe. Restore moves it to a new phone.
