Ashibur's Account world - installable web app

These files must be put on a website that uses HTTPS. Chrome on Android will not
offer "Install app" for a file opened directly from the phone.

1. Upload every file in this folder (index.html, manifest.webmanifest, sw.js and
   the three icon-*.png files) to the same folder on any HTTPS host.
2. On the phone, open that address in Chrome. After you have tapped around for
   about 30 seconds, use the menu and choose "Install app" (or "Add to Home
   screen"). An "Install app" button may also appear inside the page.
3. The app then opens full screen from its own icon and works without internet.

Your entries are stored only on that phone. Use "Back up" now and then and keep
the file somewhere safe. "Restore" loads a backup, for example on a new phone.

After you change any file, edit the version name in sw.js (account-world-v1) so
phones pick up the update.
